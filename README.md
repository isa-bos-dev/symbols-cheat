# λ Symbols Cheat

---

A landing page with the symbols used in mathematical formulas — Greek letters, blackboard bold, calligraphic, fraktur and operators — ready to copy and paste into Markdown, LaTeX, HTML or VS Code with a single click.

## ✨ Features

- **One-click copy** of the glyph itself, its LaTeX command, its HTML entity or its Unicode code point.
- **Categories**: Greek alphabet (with variants such as `ϵ`, `ϑ`, `ϕ`), blackboard bold (`ℝ ℂ ℕ ℤ`), calligraphic/script (`ℒ ℋ ℱ`), fraktur (`𝔤 𝔭`) and calculus/logic operators (`∇ ∂ ∞ ∫ ∀ ∃`).
- **Search** by symbol, name, LaTeX command or HTML entity.
- **Table and card views**.
- **"Most used" ribbon** with the most common symbols always at hand.
- **Scratchpad with live preview** to check how a formula renders before pasting it.
- **Quick guide** for Markdown math syntax, HTML entities and the native Unicode pickers on Windows/macOS.

## 🧭 How to use

### Copy a symbol

Click anything in the table and it goes straight to your clipboard. Each column copies a different format of the same symbol:

| Click on… | You get | Use it in |
|---|---|---|
| The glyph (`γ`) | The character itself | Any text, VS Code, chats, docs |
| The LaTeX command (`\gamma`) | The command | LaTeX, Markdown math (`$\gamma$`) |
| The HTML entity (`&gamma;`) | The entity | HTML, Markdown tables and headings |
| The Unicode code (`U+03B3`) | The code point | Character pickers, code |

The button in the last column copies the lowercase and uppercase pair together (`γ Γ`).

### Find a symbol fast

- Press `/` anywhere on the page to jump to the search box.
- Search by name (`lambda`), by the symbol (`λ`), by LaTeX (`\lambda`) or by HTML entity (`&lambda;`).
- Use the category tabs to narrow the list, and switch between **Table** and **Cards** views.

### Draft a formula in the scratchpad

1. Type in the scratchpad, or insert one of the **quick snippet templates**.
2. Hold `Shift` while clicking any symbol in the table to add it to the scratchpad (it is also copied).
3. The **preview** next to it shows the formula rendered, just as it will look in your document.
4. Press **Copy all** and paste it into your Markdown file.

### Write math in Markdown (VS Code, GitHub)

- Inline formula: `$\alpha + \beta$` — no spaces right after the opening `$` or before the closing one.
- Block formula, centered on its own line: `$$\sum_{i=1}^n x_i$$`.
- No math support available? Paste the glyph itself (`α`) or the HTML entity (`&alpha;`), which render in any Markdown viewer.

> The page needs an internet connection on first load, since its styles, fonts and the formula renderer come from public CDNs.
